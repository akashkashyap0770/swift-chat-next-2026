# 💬 SwiftChat — Real-Time Messaging App

A full-stack real-time chat application built with **Next.js, MongoDB, Socket.io, and JWT Authentication**.  
SwiftChat allows users to register, log in, and communicate instantly via global or private chats.

---

## ✨ Features

- 🔐 Authentication (Register / Login / Logout)
- 🍪 Secure JWT-based auth with HTTP-only cookies
- 🟢 Real-time messaging using Socket.io
- 🌐 Global chat (everyone can chat together)
- 👤 Private messaging (1-to-1 chat)
- 🟢 Online / Offline user status
- 📜 Persistent chat history (MongoDB)
- ⚡ Instant UI updates (no refresh needed)
- 📱 Responsive UI with Tailwind CSS

---

## 🛠️ Tech Stack

### Frontend
- Next.js (App Router)
- React.js
- Tailwind CSS

### Backend
- Next.js API Routes
- Node.js
- MongoDB + Mongoose

### Real-Time
- Socket.io (WebSockets)

### Authentication
- JWT (JSON Web Tokens)
- HTTP-only Cookies
